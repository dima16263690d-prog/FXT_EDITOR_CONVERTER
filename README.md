# FXT_EDITOR_CONVERTER

Инструмент для **GTA San Andreas**, который конвертирует текстовые FXT-таблицы между обычным TXT и форматом FXT с учётом таблицы `FONTS.dtf`.

Программа рассчитана на Windows и не требует установки отдельного приложения: используются обычные `.bat` и PowerShell-скрипты.

## Возможности

- **TXT → FXT** с учётом `FONTS.dtf`
- **FXT → TXT** с обратным преобразованием символов
- поддержка русской Windows-1251 и других входных кодировок
- автоматическое определение кодировки TXT
- обработка таблицы `SYMB=` из `FONTS.dtf`
- совместимое с FXT Editor преобразование символов
- поиск и исправление дубликатов ключей
- создание резервной копии исходного TXT перед автоматическим исправлением
- отчёт о дубликатах в `.duplicates.log`
- режим диагностики таблицы `FONTS.dtf`

---

## 1. Что находится в архиве

Основные файлы:

| Файл | Назначение |
|---|---|
| `FXT_CONVERTER.bat` | Простой запуск TXT → FXT |
| `FXT_DECODER.bat` | Простой запуск FXT → TXT |
| `fxt_convert_dtf.ps1` | Основной конвертер TXT → FXT |
| `fxt_decode.ps1` | Декодер FXT → TXT |
| `FONTS.dtf` | Таблица символов GTA / `SYMB=` |
| `check.ps1` | Проверка файлов побайтным сравнением |

Для обычной работы достаточно использовать **два BAT-файла**.

# 2. Требования

### Операционная система

- Windows
- PowerShell

BAT-файлы запускают:

`powershell.exe`

Поэтому на обычной Windows дополнительная установка PowerShell не требуется.

### FONTS.dtf

Для правильного преобразования символов необходим файл:

`FONTS.dtf`

Конвертер автоматически ищет его в следующем порядке:

1. рядом с входным TXT/FXT;
2. рядом с самим PowerShell-скриптом;
3. по переменной окружения `FXT_FONTS`;
4. в текущей рабочей папке.

Самый простой вариант — положить `FONTS.dtf` **рядом с программой**.

---

# 3. TXT → FXT

Это основной режим для создания FXT-файлов из обычного текста.

## Самый простой способ

Просто перетащите один или несколько TXT-файлов на:

`FXT_CONVERTER.bat`

Например:

`GANG.txt`

после обработки:

`GANG.fxt`

Также рядом может появиться:

`GANG.duplicates.log`

Если программа исправляла дубликаты исходного TXT, будет создана резервная копия:

`GANG.txt.bak`

## Формат исходного TXT

Каждая строка должна иметь вид:

`KEY TEXT`

Например:

`BALSHOW Баланс банка: $~1~`

`GANGM1 Бизнес банды`

`GANGM2 Семейный банк`

Ключ:

- автоматически переводится в верхний регистр;
- должен содержать только `A-Z`, цифры и символ `_`.

Пустые строки и строки, начинающиеся с `#`, игнорируются.

---

# 4. Что делает FXT_CONVERTER.bat

BAT запускает:

`fxt_convert_dtf.ps1`

с параметрами:

`-FixDuplicates -PreferLast -FixSourceTxt`

То есть стандартный запуск автоматически:

1. читает TXT;
2. определяет его кодировку;
3. загружает `FONTS.dtf`;
4. читает таблицу `SYMB=`;
5. преобразует символы в формат GTA FXT;
6. ищет дубликаты ключей;
7. при дубликатах оставляет **последнее найденное значение**;
8. создаёт резервную копию исходного TXT;
9. исправляет исходный TXT;
10. создаёт FXT;
11. создаёт отчёт `.duplicates.log`.

Это поведение сделано для удобной подготовки FXT-файлов к использованию в GTA San Andreas.

---

# 5. Дубликаты ключей

Например, если TXT содержит:

`HELLO Первый текст`

`HELLO Второй текст`

ключ `HELLO` встречается два раза.

Стандартный `FXT_CONVERTER.bat` использует:

`-PreferLast`

поэтому будет сохранён:

`HELLO Второй текст`

Перед изменением исходного файла создаётся:

`HELLO...`

резервная копия с расширением:

`.bak`

Например:

`GANG.txt.bak`

Подробная информация о найденных дубликатах записывается в:

`GANG.duplicates.log`

---

# 6. Поддерживаемые кодировки TXT

PowerShell-конвертер поддерживает:

- `auto`
- `utf-8`
- `utf-8-bom`
- `utf-16le`
- `utf-16be`
- `cp1251`
- `cp1252`
- `cp866`
- `koi8-r`
- `iso-8859-5`
- `ascii`

По умолчанию используется:

`-Encoding auto`

В автоматическом режиме проверяются BOM и UTF-8. Если файл не определяется как UTF-8, для текста с расширенными байтами используется Windows-1251.

Для русских GTA-текстов обычно подходит **Windows-1251 / CP1251**.

---

# 7. FXT → TXT

Для обратного преобразования используйте:

`FXT_DECODER.bat`

Перетащите на него один или несколько FXT-файлов.

Например:

`GANG.fxt`

будет преобразован в:

`GANG.decoded.txt`

Декодер:

1. читает FXT как массив байтов;
2. находит `FONTS.dtf`;
3. читает `SYMB=`;
4. строит обратную таблицу символов;
5. восстанавливает CP1251;
6. создаёт обычный TXT.

По умолчанию TXT создаётся в:

**UTF-8 с BOM**.

---

# 8. Командная строка

## Конвертация TXT → FXT

Один файл:

```bat
FXT_CONVERTER.bat input.txt
```

Несколько файлов:

```bat
FXT_CONVERTER.bat first.txt second.txt third.txt
```

---

## Декодирование FXT → TXT

```bat
FXT_DECODER.bat input.fxt
```

Можно передавать несколько файлов:

```bat
FXT_DECODER.bat first.fxt second.fxt third.fxt
```

BAT автоматически создаёт файлы с суффиксом:

`.decoded.txt`

---

# 9. Прямой запуск PowerShell

При необходимости можно запускать скрипты напрямую.

## TXT → FXT

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\fxt_convert_dtf.ps1" ".\GANG.txt"
```

### Указать выходной файл

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\fxt_convert_dtf.ps1" ".\GANG.txt" -OutputFile ".\GANG_NEW.fxt"
```

### Явно указать CP1251

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\fxt_convert_dtf.ps1" ".\GANG.txt" -Encoding cp1251
```

### Строгая проверка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\fxt_convert_dtf.ps1" ".\GANG.txt" -Strict
```

При `-Strict` некорректные строки и символы приводят к ошибке вместо молчаливого пропуска или замены.

### Диагностика FONTS.dtf

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\fxt_convert_dtf.ps1" ".\GANG.txt" -Diagnose
```

Этот режим показывает, какие CP1251-байты обрабатываются через:

- `SYMB=`
- таблицу homoglyphs
- прямой byte passthrough

# 10. Переменная FXT_FONTS

Можно указать отдельный путь к `FONTS.dtf`.

Например:

```bat
set FXT_FONTS=D:\Grand Theft Auto San Andreas\models\FONTS.dtf
FXT_CONVERTER.bat GANG.txt
```

или в PowerShell:

```powershell
$env:FXT_FONTS = "D:\Grand Theft Auto San Andreas\models\FONTS.dtf"
```

После этого конвертер сможет использовать указанную таблицу.

---

# 11. Важный момент для русского языка

Не следует просто сохранять текст в произвольной кодировке и ожидать, что GTA автоматически правильно его прочитает.

Этот проект использует:

`FONTS.dtf → SYMB=`

для построения соответствия между байтами исходного текста и байтами, ожидаемыми FXT/GTA.

Поэтому **`FONTS.dtf` является важной частью конвертации**.

Если `FONTS.dtf` отсутствует, программа завершит работу с ошибкой:

`FONTS.dtf not found.`

---

# 12. Как использовать для перевода GTA SA

Обычный рабочий процесс:

```text
1. Получить TXT с GXT/FXT строками
             ↓
2. Отредактировать русский текст
             ↓
3. Проверить ключи и дубликаты
             ↓
4. Перетащить TXT на FXT_CONVERTER.bat
             ↓
5. Получить .fxt
             ↓
6. Установить FXT в нужное место мода
             ↓
7. Проверить текст в GTA San Andreas
```

Для обратной проверки:

```text
GTA FXT
   ↓
FXT_DECODER.bat
   ↓
decoded.txt
   ↓
проверка русского текста и ключей
```

# 13. Если GTA не показывает русский текст

Проверьте:

1. Есть ли `FONTS.dtf`.
2. Используется ли правильный `FONTS.dtf`.
3. Не повреждены ли ключи FXT.
4. Нет ли лишних дубликатов ключей.
5. Есть ли русский символ в таблице `SYMB=`.
6. Не содержит ли TXT символов, которые невозможно представить в CP1251.
7. Правильно ли установлен полученный FXT в игре.

Для диагностики используйте:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\fxt_convert_dtf.ps1" ".\GANG.txt" -Diagnose
```

---

# 14. Результаты работы

После конвертации рядом с исходным TXT обычно находятся:

```text
GANG.txt
GANG.txt.bak
GANG.fxt
GANG.duplicates.log
```

Файл `.bak` создаётся только при автоматическом исправлении исходника и наличии дубликатов.

Файл `.duplicates.log` содержит информацию о найденных повторяющихся ключах.

---

# 15. Безопасность исходного текста

При стандартном запуске через `FXT_CONVERTER.bat` исходный TXT может быть автоматически переписан для удаления дубликатов.

Перед этим создаётся резервная копия:

```text
original.txt
original.txt.bak
```

Если исходный текст нельзя изменять, запускайте PowerShell-конвертер без:

`-FixSourceTxt`
